このディレクトリは、`closure-phase-specs` の過去版・旧適用例・旧ツールを履歴として保存する領域である。

**archive 内の文書は現行正本ではない。**

現行正本は、リポジトリrootの番号付き文書と `PUBLICATION_POLICY.md` を参照すること。

過去版には、当時の状態を保存するため、英語先行構成、旧名称、旧読書順、旧公開境界、旧適用例、旧ツール等が残り得る。

それらは現在の理論群・公開方針を定義しない。

archive 内の旧版は、歴史状態を保存するため原則として無言修正しない。現行の誤り修正・理論更新はrootの新しい版で行う。
